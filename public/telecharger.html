Télécharger A'rms

Le launcher de bureau pour jouer à A'rms directement depuis Windows, sans passer par le navigateur.

Version 1.0.0 — Windows

⬇ Télécharger le launcher (.exe)
Installateur Windows · ~77 Mo

Installation

  1. Clique sur le bouton ci-dessus pour télécharger l'installateur.
  2. Ouvre le fichier téléchargé (Arms-Setup-1.0.0.exe) une fois le téléchargement terminé.
  3. Si Windows affiche un écran bleu « Windows a protégé votre ordinateur », clique sur « Informations complémentaires » puis sur « Exécuter quand même ».
  4. Laisse l'installation se terminer, puis lance A'rms depuis le raccourci créé sur le Bureau ou dans le menu Démarrer.
Pourquoi cet avertissement Windows ? Le launcher n'est pas encore signé numériquement — Windows affiche donc par prudence un avertissement pour tout programme peu téléchargé, même inoffensif. C'est normal et ça n'empêche pas d'installer le jeu.
